## 結論

- **グローバルIPアドレス** = インターネット全体で **一意**な住所。ISP が割り当て、世界中からの通信の宛先になれる。
- **ローカル（プライベート）IPアドレス** = 家庭内・社内などの **LAN の中だけ**で通用する住所。そのままではインターネットに出られない。
- 両者の橋渡しをするのが **ルーターの NAT**。家庭では複数の機器が 1 つのグローバルIPを共有してインターネットにアクセスしている。

## 詳しく

### グローバルIP
- インターネット上で重複しないよう、ICANN→各地域のレジストリ→ISP という形で管理・割り当てされる。
- 外部のサーバーやサービスと直接通信できる「公の住所」。
- 一般家庭では ISP から **動的に**割り当てられることが多く、時々変わる。固定したい場合は固定IPサービスを契約する。

### ローカル（プライベート）IP
- LAN 内の機器（PC・スマホ・プリンタなど）を区別するための住所。ルーター（DHCP）が自動で配ることが多い。
- インターネットには重複して存在してよい（各家庭の `192.168.x.x` が世界中で使われている）。
- **RFC 1918** で予約されている私用アドレス範囲:

  | 範囲 | CIDR | よく使われる例 |
  | --- | --- | --- |
  | `10.0.0.0` 〜 `10.255.255.255` | `10.0.0.0/8` | 企業ネットワーク |
  | `172.16.0.0` 〜 `172.31.255.255` | `172.16.0.0/12` | 中規模ネットワーク |
  | `192.168.0.0` 〜 `192.168.255.255` | `192.168.0.0/16` | 家庭用ルーター |

### NAT が橋渡しする
ローカルIPの機器がインターネットへ出るとき、ルーターが送信元アドレスを
**ローカルIP → グローバルIP** に書き換える。これが **NAT (Network Address Translation)** で、
家庭ではポート番号も使って複数機器を 1 つのグローバルIPに多重化する **NAPT（PAT / IPマスカレード）** が使われる。

```
[PC 192.168.1.10] ┐
[スマホ 192.168.1.11] ├─[ルーター]──(グローバルIP 203.0.113.5)──> インターネット
[TV 192.168.1.12] ┘        ↑ここで NAT 変換
```

この仕組みのおかげで、枯渇しがちな IPv4 のグローバルIPを節約できている。

### 自分のIPの確認方法
- **ローカルIP**: Windows は `ipconfig`、macOS / Linux は `ifconfig` または `ip addr`。
- **グローバルIP**: 「[確認くん](https://www.ugtop.com/spill.shtml)」などの外部サイトにアクセスするか、ルーターの管理画面で確認する。

## 補足

- **IPv6** ではアドレスが潤沢なため、各機器がグローバルなアドレスを持てる設計で、NAT 前提の IPv4 とは事情が異なる。
- ローカルIPは外から直接アクセスできないため、外部公開したい場合は **ポートフォワーディング** や VPN、トンネリングサービス等が必要になる。
